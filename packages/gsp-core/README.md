# gsp-core

Backend-independent GSP semantic records, capabilities, diagnostics, discovery, and sessions.

`gsp-core` is the protocol-only foundation of GSP. It imports as `gsp`, depends on no rendering
backend, and discovers optional providers lazily through entry-point metadata.

The package is an unpublished 0.2 alpha candidate. See the
[GSP repository](https://github.com/vispy/gsp) for the canonical specification, conformance
fixtures, qualification evidence, and release status.
